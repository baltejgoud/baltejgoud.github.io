第二章 CASE STUDY 01 — FLAGSHIP

संकेत — "THE SIGNAL"

SANKET

One demand signal, refracted into every future worth planning for.

The problem

In fashion, electronics, pharma and farm supply, demand forecasting still happens in spreadsheets. Buyers over-order into dead inventory or under-order into stockouts — and in regulated verticals, every wrong move leaves an audit problem behind it.

The build

SANKET is a multi-tenant predictive analytics SaaS that forecasts SKU-level demand and recommends purchase configurations across four verticals — with bank-grade tenant isolation and compliance-ready audit trails baked into the data layer, not bolted on.

Why it's different

Instead of one model for everything, SANKET routes each SKU to whichever model earns it — XGBoost, Prophet, statistical ensembles — and falls back to a zero-shot foundation model (Amazon Chronos) when a product is too new to have history. Cold-start is a solved path, not an excuse.

01

Challenge

Serve four industries with contradictory constraints from a single codebase. Pharma demands FDA 21 CFR Part 11 audit trails; fashion demands seasonal velocity; electronics demands lifecycle-aware forecasting; agro demands regional weather sensitivity. One platform, four rulebooks — and every tenant's data legally invisible to every other tenant.

02

System

PRESENTATION

React dashboard — Vite + TypeScript

A single-page analytics portal surfacing sell-through, margin opportunity and simulated stockouts, speaking to the backend over JWT-authenticated APIs.

GATEWAY + DATA

FastAPI gateway — PostgreSQL 16, multi-tenant

Session-level Row-Level Security enforces tenant isolation inside a shared database. Vertical routers, Alembic migrations, and GxP audit logs for medical inventory live here.

INTELLIGENCE

ML inference service — ensemble + foundation

A dedicated Python service routes each SKU to its optimal model — XGBoost, Prophet, statistical ensembles — with a zero-shot Chronos foundation-model fallback for products with thin history.

03

Engineering detail

Tenant isolation
PostgreSQL session parameters drive Row-Level Security policies, so a tenant's queries physically cannot see another tenant's rows — isolation enforced by the database, not by application discipline.
GxP audit trail
Append-only transaction histories with cryptographically signed audit logs for pharmaceutical batch changes, designed against FDA 21 CFR Part 11.
Cold-start coverage
When a SKU lacks the history to train a time-series model, the router invokes a preloaded Amazon Chronos foundation model — zero-shot forecasts from day one.
Operations
Docker Compose and Kubernetes deployment, Prometheus metrics, Grafana dashboards, Pytest coverage — observable and reproducible from a cold clone.
04

Outcome & lessons

SANKET proved I can carry a product from schema design to pixel polish: a three-layer architecture, four vertical rulebooks, regulated-industry compliance patterns, and a dashboard I'd put in front of a paying customer. The hardest lesson — multi-tenancy is a data-layer problem. Solve it in PostgreSQL and every layer above gets simpler.

CASE DOSSIER — 02 / ディープフェイク検出

AI-Based Deepfake Detection

Using artificial intelligence to fight artificial intelligence.

Overview

A deep learning method that distinguishes AI-generated fake videos from real ones, automatically detecting both replacement and reenactment deepfakes from raw video input.

Pipeline

  1. Input video — raw footage fed in
  2. Frame extraction — split into frames
  3. ResNeXt CNN — spatial feature extraction
  4. LSTM RNN — temporal pattern analysis
  5. Verdict — real or fake

Feature extraction

The ResNeXt CNN captures subtle facial artifacts, boundary inconsistencies and texture anomalies invisible to the human eye — the fingerprints of manipulation.
