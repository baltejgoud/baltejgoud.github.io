🌐 PRISMA — Enterprise Predictive Analytics SaaS

High-performance vertical SaaS platform with a multi-model forecasting engine

📌 Overview

PRISMA is a vertically-integrated, multi-tenant SaaS application that optimizes supply chains for three highly regulated or fast-moving industries: Apparel & Fashion, Consumer Electronics, and Pharmaceuticals. It utilizes an ensemble of machine learning models to predict SKU-level demand and recommend purchase configurations.

⚙️ Vertically Integrated Architecture

Frontend React Dashboard (Vite + TS)

Real-time analytics portal displaying sell-through indicators, margin opportunities, and simulated stockouts. Structured as a single-page application communicating with backend APIs via JWT-authenticated requests.

FastAPI Gateway & Multi-tenant Database (PostgreSQL 16)

Core backend API utilizing session-level Row-Level Security (RLS) to enforce tenant isolation. Houses compliance-ready GxP audit logs for medical inventory, Alembic migration systems, and vertical routers.

ML Inference API (Foundation + Statistical Ensemble)

Dedicated Python ML service which routes inference queries to the optimal model for each SKU (ranging from XGBoost and Prophet to statistical models). Features a zero-shot foundation model fallback (Amazon Chronos) for new SKUs with short history.

🛠️ Key Engineering Highlights

  • Row-Level Security (RLS): Uses PostgreSQL session parameters to restrict data visibility per tenant, ensuring bank-grade data isolation in a shared database.
  • GxP Audit Trail: Complies with FDA 21 CFR Part 11 regulations by implementing append-only transaction histories and cryptographically signed audit logs for pharmaceutical batch changes.
  • Zero-Shot Chronos Fallback: Automatically invokes a preloaded foundation model when historical data is insufficient for standard time-series training.
  • Infra as Code & Observability: Deployed via Docker Compose / K8s with integrated Prometheus metrics collection and Grafana dashboard visualization.
