# Portfolio artwork · 17 October 2026

Visual reference: https://www.jameschugh.com/ (inspected in the browser at desktop and phone sizes). The reference supplied the illustrated-world, paper, map, card, gift and pinboard direction. Its images were not copied. All four new images were produced with the built-in Image Generation tool, then resized/encoded to WebP with Sharp. No CLI image-generation fallback was used.

Existing photographs and product images remain the user's assets: `public/assets/portrait.webp`, `public/images/id-photo.webp`, and `public/assets/work/`.

No text, no labels, no logos, no UI, no watermark. Landscape should cover the whole image edge to edge.
